よくあるご質問

Q. このドメインを p=reject に上げてよいかは、どこで分かりますか？
A. 集約レポートを取り込み、左のメニューの「reject 移行準備」を開きます。判定（移行可能 / 条件つき（要対応あり） / 準備未完了 / 判断材料が不足しています）、通過率のゲージ、推奨アクション、reject にした場合に拒否される見込みが表示されます。通過率の帯の値（75%・90%・99%）は運用目安で、公式の根拠はありません。詳しくはマニュアル第 3 章をご覧ください。
Q. このツールは Microsoft 365 の設定を変更しますか？
A. 変更しません。画面からの Microsoft 365 の取得は、共有メールボックスの読み取り権限（Mail.Read.Shared）だけを使い、メールの削除・移動・既読化・送信は行いません。コマンドライン（CLI）には、取得後にメールを削除するモードがあります。DNS 設定も変更しません。
Q. 解析対象のデータはクラウドに送信されますか？
A. 解析結果は PC 内に保存し、外部の AI やクラウドの解析サービスには送りません。Microsoft 365 への接続は、利用者が設定した場合に限ります。
Q. Microsoft 365 連携は必須ですか？
A. 必須ではありません。連携を使わず、DMARC レポートファイル（XML / ZIP / GZ）を直接取り込んで利用することもできます。
Q. 分類の判定はどのように行われていますか？
A. ルールベースの判定が、DMARC の結果、受信側が報告した例外の理由、設定画面に登録した自社 IP・転送サーバーから判定します。AI 推論や機械学習は使用していません。同一入力に対して常に同一の結果を返します。条件はマニュアル第 4 章に掲載しています。
Q. 設定画面に登録した自社 IP や転送サーバーは、判定に使われますか？
A. 使われます。保存した内容は、次の分析から反映され、アプリの再起動は不要です。メールボックスからの取り込みと CLI も同じ設定を使います。保存済みの記録は、「reject 移行準備」の登録の操作から再判定でき、区分ごとの件数の変化が表示されます。
Q. 保存されたデータはどこにありますか？ 削除したい場合は？
A. 設定・解析結果は %LocalAppData%\DmarcAnalysisAssistant 配下に保存されます。設定画面の「保存済みDMARC解析データを削除」から保存済みDMARC解析結果と処理済みマーカーを削除できます。この操作では、設定、同意情報、管理区分メモ、バウンス分析データは削除されません。
Q. 「なりすまし疑い」と表示された場合、すぐに対応が必要ですか？
A. 判定は参考情報です。送信元 IP、認証結果、送信経路を確認したうえで、組織のセキュリティ担当者と相談して対応方針を決めてください。機械判定のため、すべての事例を正確に分類できるとは限りません（免責事項 第2条）。
Q. アプリが起動しない・WebView2 エラーが出る
A. Microsoft Edge WebView2 Runtime がインストールされているか確認してください（Windows 11 には通常プリインストールされています）。未インストールの場合は Microsoft の公式ページからインストールできます。
Q. バージョンアップの通知はありますか？
A. Microsoft Store 経由でインストールされた場合は Store の自動更新機能に従います。アプリ内の「このアプリについて」で、お使いのバージョンを確認できます。

Frequently Asked Questions

Q. Where can I see whether this domain can move to p=reject?
A. Import your aggregate reports and open "Readiness for reject" in the left menu. It shows a verdict (Ready to move / Conditional (action needed) / Not ready / Not enough information to decide), a pass-rate gauge, recommended actions, and the expected rejections if you move to reject. The band values (75%, 90%, 99%) are operational guidelines with no official basis. See Chapter 3 of the manual.
Q. Does this tool modify Microsoft 365 settings?
A. No. Fetching from the app screen uses only the read permission for shared mailboxes (Mail.Read.Shared) and never deletes, moves, marks as read, or sends mail. The command-line interface (CLI) has a mode that deletes mail after fetching it. The tool does not change DNS settings.
Q. Is analysis data transmitted to the cloud?
A. Analysis results are stored on your PC and are not sent to external AI or cloud analysis services. Microsoft 365 connections are made only when you configure them.
Q. Is Microsoft 365 integration required?
A. No. You can use the tool by directly importing DMARC report files (XML / ZIP / GZ) without enabling Microsoft 365 integration.
Q. How does the classification work?
A. A rule-based engine uses the DMARC result, the exception reasons reported by receivers, and the own IPs and forwarding servers you registered on the settings screen. No AI inference or machine learning is used. The same input always produces the same result. The conditions are in Chapter 4 of the manual.
Q. Are the own IPs and forwarding servers I register on the settings screen used?
A. Yes. Saved settings apply from the next analysis, and no restart is needed. Mailbox import and the CLI use the same settings. You can re-evaluate saved records with the registration actions in "Readiness for reject", and the change in counts per category is shown.
Q. Where is stored data kept, and how can I delete it?
A. Settings and analysis results are stored locally under %LocalAppData%\DmarcAnalysisAssistant. Open Settings and use "Delete stored DMARC analysis data" to clear saved DMARC analysis results and processed markers. This keeps settings, consent information, management notes, and bounce analysis data.
Q. If "Spoofing suspected" is shown, do I need to act immediately?
A. The classification is advisory. Review source IP, authentication results, and sending path, and consult with your security team. Since the result is machine-generated, not every case can be classified correctly (Disclaimer, Article 2).
Q. The app does not start or shows a WebView2 error.
A. Ensure Microsoft Edge WebView2 Runtime is installed (usually pre-installed on Windows 11). If not, you can install it from Microsoft's official page.
Q. How will I be notified of updates?
A. If installed via Microsoft Store, updates follow Store auto-update. You can check the version you are using under "About this app" in the application.
