プライバシーポリシー

最終更新: 2026年11月19日

解析結果は PC 内に保存し、外部の AI やクラウドの解析サービスには送りません。テレメトリ・クラッシュレポート・使用履歴の自動送信も行いません。

プライバシー通知（アプリ内表示に対応する内容）

  1. 解析対象のレポートデータと設定情報は、ローカル端末に保存します。バウンスメール本文を含め、これらを外部の AI やクラウドの解析サービスへ送信することはありません。
  2. Microsoft 365 への接続は、利用者が設定画面で明示的に設定した場合に限り行われます。画面からの取得で使用する権限は、共有メールボックスの読み取り権限（Mail.Read.Shared）のみで、メールの削除・移動・既読化・送信は行いません。
  3. Microsoft 365 の認証トークンはメモリ上に一時保持されるのみで、ディスクへの永続化は行いません。アプリを終了すると破棄されます。
  4. 分類結果、IP アドレス、認証結果、ドメイン情報などを外部サービスへ送信することはありません。クラウド解析や外部 AI API への問合せも行いません。
  5. 利用状況のテレメトリ、クラッシュレポート、使用履歴の自動送信・収集は行いません。
  6. 設定情報と解析結果はローカル端末の %LocalAppData%\DmarcAnalysisAssistant 配下に保存され、利用者の操作で削除できます。

補足説明

収集・保存するデータ

本ソフトウェアがローカル端末上に保存するデータは次のとおりです。いずれも %LocalAppData%\DmarcAnalysisAssistant 配下に保存され、アンインストールまたは利用者の操作で削除できます。

  • 取込んだ DMARC 集約レポートの解析結果（レコード、公開ポリシー、受信側の判定など）
  • 処理済みメールのマーカー
  • 設定画面に登録した自社メールサーバーの IP 範囲、転送サーバーの IP 範囲
  • アプリ設定（Microsoft 365 のテナント ID・クライアント ID・メールボックスのアドレス、同意情報、管理区分メモなど）

Microsoft 365 連携（任意機能）

利用者が設定画面で Microsoft 365 連携を設定した場合に限り、Microsoft Graph API を用いて共有メールボックスから DMARC レポートおよびバウンスメールを取得します。

  • 画面からの取得で使用する権限: Mail.Read.Shared（読み取り）
  • 画面からの取得では、メールの削除・移動・既読化・送信は行いません。
  • 認証トークンはメモリ上にのみ保持され、ディスクには保存されません。アプリを終了すると破棄されます。

外部サービスへの送信

解析結果（分類結果、IP アドレス、認証結果、ドメイン情報、レポート本文）を、外部の AI やクラウドの解析サービスへ送信することはありません。テレメトリ収集、広告配信も行いません。

データの削除

保存データは利用者の操作でいつでも削除できます。

  • 設定画面の「保存済みDMARC解析データを削除」から、保存済みDMARC解析結果と処理済みマーカーを削除できます。
  • この操作では、設定情報、同意情報、管理区分メモ、バウンス分析データは削除されません。
  • Windows の「アプリのアンインストール」

第三者サービス

  • Microsoft 365 Graph API: 利用者が連携を設定した場合のみ通信します。
  • Microsoft Edge WebView2 Runtime: GUI 表示に使用します。Microsoft のライセンスおよびプライバシー条項に従います。

プライバシーポリシーの変更

本ポリシーは予告なく変更されることがあります。重要な変更がある場合はアプリ内および本ページで通知します。

Privacy Policy

Last updated: November 19, 2026

Analysis results are stored on your PC and are never sent to external AI or cloud analysis services. No telemetry, crash reports, or usage history are automatically collected or sent.

Privacy Notice (corresponding to the in-app text)

  1. Report data and configuration information are stored on the user's device. They, including bounce message contents, are never sent to external AI or cloud analysis services.
  2. Microsoft 365 connections are made only when explicitly configured by the user on the settings page. The permission used for fetching from the app screen is limited to the read permission for shared mailboxes (Mail.Read.Shared), and the app screen does not delete, move, mark as read, or send mail.
  3. Microsoft 365 authentication tokens are held in memory only and are never persisted to disk. They are discarded when the application exits.
  4. Classification results, IP addresses, authentication results, and domain information are not sent to any external service. No queries are made to cloud analysis platforms or external AI APIs.
  5. Telemetry, crash reports, and usage history are not collected or transmitted automatically.
  6. Configuration and analysis results are stored under %LocalAppData%\DmarcAnalysisAssistant on the user's device and can be deleted by the user.

Supplementary Notes

Data collected and stored

The software stores the following data locally on your device. All data is stored under %LocalAppData%\DmarcAnalysisAssistant and can be deleted by uninstalling the app or through user actions.

  • Analysis results of imported DMARC aggregate reports (records, published policy, receiver decisions, etc.)
  • Processed-mail markers
  • The IP ranges of your own mail servers and forwarding servers registered on the settings screen
  • Application settings (Microsoft 365 tenant ID, client ID, and mailbox addresses, consent information, management notes, etc.)

Microsoft 365 integration (optional)

Only when the user configures Microsoft 365 integration on the settings page, the software uses Microsoft Graph API to read DMARC reports and bounce messages from a shared mailbox.

  • Permission used for fetching from the app screen: Mail.Read.Shared (read)
  • Fetching from the app screen does not delete, move, mark as read, or send mail.
  • Authentication tokens are held in memory only and are never persisted to disk. They are discarded on application exit.

Transmission to external services

Analysis results (classification results, IP addresses, authentication results, domain information, and report contents) are never sent to external AI or cloud analysis services. The software performs no telemetry collection and no ad delivery.

Data deletion

Stored data can be deleted at any time by the user.

  • Use "Delete stored DMARC analysis data" in Settings to delete saved DMARC analysis results and processed markers.
  • This action does not delete settings, consent information, management notes, or bounce analysis data.
  • Uninstalling the app via Windows "Apps & features"

Third-party services

  • Microsoft 365 Graph API: used only when the user configures integration.
  • Microsoft Edge WebView2 Runtime: used for GUI rendering; subject to Microsoft's license and privacy terms.

Changes to this policy

This policy may be updated without prior notice. Significant changes will be announced in the application and on this page.
