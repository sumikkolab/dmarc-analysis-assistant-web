# DMARC 分析支援ツール

**このドメインを p=reject に上げてよいか。上げられないなら、何が原因で、何をすればよいか。**

[English README](README.md)

この README は 1.1.0.0 向けです。reject 移行準備・転送の影響は 1.1.0.0 以降の機能です。

## このツールについて

DMARC 分析支援ツールは、DMARC 集約レポート（XML / ZIP / GZ）と関連するバウンスメールを取り込み、DMARC ポリシーを p=reject に上げてよいかを判断できるように示す Windows デスクトップアプリです。上げられない場合は、何が原因で、次に何をすればよいかを示します。

解析結果は PC 内に保存し、外部の AI やクラウドの解析サービスには送りません。

## reject 移行準備

レポートを取り込んだら、左のメニューの「reject 移行準備」を開きます。

- **判定（4 値）:** 移行可能 / 条件つき（要対応あり） / 準備未完了 / 判断材料が不足しています
- **通過率のゲージ:** 75%・90%・99% の目盛り。**帯の値は運用目安（公式の根拠なし）です。**
- **推奨アクション:** 判定と矛盾しない次の一手。reject への変更を促すのは「移行可能」のときだけです。
- **reject にした場合に拒否される見込み:** 自社送信元の認証失敗・判定保留・なりすまし疑い・転送経由の可能性の内訳と、最小（なりすまし疑いだけ）から最大（DMARC に失敗した全件）の範囲。
- **判定の根拠:** 公式の根拠がある項目（RFC 9989・RFC 9990、Microsoft・Google の文書。出典つき）と、運用目安を区別して表示。
- **転送の影響:** 通過率を「全体」と「転送経由の可能性を除く」で並べ、除いた件数を併記。失敗した転送の送信元を、転送サーバーとして登録できます。

## 分類

各レコードを、DMARC の結果、受信側が報告した例外の理由、設定画面に登録した IP 範囲から、決定論的なルールで判定します。登録した内容は次の分析から反映され、メールボックス取り込みと CLI も同じ設定を使います。

| 分類 | 条件 |
|------|------|
| **正常** | DMARC が pass している。 |
| **自社送信元の認証失敗** | DMARC が fail し、送信元 IP が、登録した自社メールサーバーの IP 範囲に含まれる。 |
| **転送経由の可能性** | DMARC が fail し、送信元 IP が登録した転送サーバーの IP 範囲に含まれるか、受信側が `trusted_forwarder` または `mailing_list` と報告している。 |
| **なりすまし疑い** | DMARC が fail し、上記のどれにも当てはまらない。 |
| **判定保留** | DMARC が fail し、上記のどれにも当てはまらず、既知の送信サービスとして照合されたもの。現在の設定画面には登録の項目がないため、通常は付かない。 |

## 主な機能

- フォルダまたは Microsoft 365 の共有メールボックスから DMARC 集約レポート（XML / ZIP / GZ）を取り込み
- ダッシュボード、レコード一覧、送信元サーバー別・ドメイン別の集計
- バウンスメール分析（Microsoft 365 または EML フォルダ。DMARC の分類とは別の機能）
- 技術レポート・経営レポート（PDF）、Excel、CSV の出力
- ドメインごとの管理区分（自社管理 / 監視のみ / 外部）。分類や集計には影響しません
- 日本語 / 英語の画面

## プライバシーとセキュリティ

- 解析結果は PC 内に保存し、外部の AI やクラウドの解析サービスには送りません
- Microsoft 365 への接続は、利用者が設定した場合に限ります
- 画面からの取得は、読み取りの権限（`Mail.Read.Shared`）だけを使い、メールの削除・移動・既読化・送信は行いません。コマンドライン（CLI）には、取得後にメールを削除するモードがあります
- 認証トークンはメモリ上にのみ保持、ディスクには保存しません
- テレメトリ・クラッシュレポート・使用履歴の自動送信 **なし**
- 保存データは `%LocalAppData%\DmarcAnalysisAssistant` 配下、利用者の操作で削除可能
- 初回起動時に同意が必要。規約更新時に再同意

## 動作環境

- Windows 10 / 11
- .NET 10（Store 版に同梱）
- Microsoft Edge WebView2 Runtime
- Microsoft 365 Graph API アクセス（任意のメール取込機能を使う場合のみ）
